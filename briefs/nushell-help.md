# Nushell Help Script

## Purpose
This brief explains the `help-aliases.nu` script, which provides a self‑documenting help system for the Nushell aliases defined in the Mastra project. The script automatically generates a readable table of all aliases, their commands, and a short description, making it easy for developers to discover and use the shortcuts.

## How It Works
1. **Alias Definition** – All aliases are defined in `src/mastra/tools/nushell-aliases.nu`.
2. **Help Command** – The `help` alias is defined in the same file and can be invoked as `help` or `help <alias>`.
3. **Output** –  
   * `help` with no arguments prints a table of all aliases, their commands, and descriptions.  
   * `help <alias>` prints the command and description for the specified alias.

## Example Usage
```nu
# List all aliases
help

# Show details for a specific alias
help station-status
```

## Installation
Add the following line to your `~/.config/nushell/config.nu` (or project‑wide config) to source the alias file:
```nu
source "$(pwd)/src/mastra/tools/nushell-aliases.nu"
```

## Alias Table (generated by `help`)

| Alias | Command | Description |
|-------|---------|-------------|
| `tdu` | `td usage --new-session` | Start a new task usage session. |
| `tdl` | `td list` | List all tasks. |
| `td-foc` | `td focus <issue-id>` | Focus on a specific task. |
| `td-unfoc` | `td unfocus` | Clear any focused task. |
| `station-status` | `td current --json | from json | get focused.issue` | Show the focused task as JSON. |
| `td-open` | `filter-tasks open` | Filter tasks with status open. |
| `td-inprog` | `filter-tasks in_progress` | Filter tasks with status in_progress. |
| `td-review` | `filter-tasks in_review` | Filter tasks with status in_review. |
| `td-all` | `td list --json | from json` | List all tasks (raw JSON). |
| `td-summary` | `td list --json | from json | select id title status priority` | Quick summary table of tasks. |
| `skg` | `skate get` | Retrieve the current skate session. |
| `sk-set` | `skate set <value>` | Set a skate configuration value. |
| `sk-del` | `skate delete <key>` | Delete a skate configuration key. |
| `td-commits` | `git log --oneline --decorate --graph` | Show recent git commits in a concise format. |
| `td-clean` | `git clean -fdx` | Remove untracked files. |
| `td-status` | `git status` | Show current git status. |
| `td-branch` | `git branch --show-current` | Show the current branch. |

## Extending the Help System
If you add new aliases, simply update the `nushell-aliases.nu` file with a `description` comment next to each alias. The `help` command will automatically include them in the generated table.

---

**Note:** The help script relies on NuShell's built‑in `table` command for formatting. Ensure NuShell is installed and added to your PATH to use these shortcuts.
